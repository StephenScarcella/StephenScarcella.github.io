# stephen-site

Personal site for Stephen Scarcella: a top-down warehouse floor (canvas, forklifts on real aisle routes) where each zone opens a section: experience, projects, resume, contact.

Static: `index.html`, `style.css`, `floor.js`. No build step.

- Edit content: the `<section>` blocks in `index.html` (the floor panel clones them).
- Links/videos with an empty `data-href` / `data-src` stay hidden until filled.
- Clips go in `media/`.
